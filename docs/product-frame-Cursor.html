The Last Broadcast

1. What it is

A single-player browser mystery about a missing overnight host at a fictional radio station.

2. Who it is for

One person who wants a short fair case, with no account and no timer.

3. Why it wins

An account is accepted only with an authored proof. Equivalent note sets count. A wrong account does not close the case.

4. How it is structured

Four rooms, object lists, a notebook, three interviews, five deductions, and one accusation. Content is separate from the rules.

5. How people find it

Run it locally. This delivery was not deployed.

6. How people use it

Explore, inspect, interview, deduce, then write the account. Hints stay on one unmet objective.

7. How they finish

The ending repeats notes already in the notebook. There is no purchase.

8. How it makes money

It does not. No ads, no leads, no payments.

9. How it launches

npm ci, then npm run dev on 127.0.0.1. Preview uses port 4173.

10. What to improve

A person should time a first play. The 15 to 25 minute figure is a target, not a measurement.
