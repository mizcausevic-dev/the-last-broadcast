# Assets

Everything drawn or heard in the game was made for this project.

- `css/game.css` is original layout and color.
- `js/scenes.js` is original SVG. The drawings are geometric: a window, reels, a door, shelves, a rack. They are decorative. The room list is the control.
- `assets/favicon.svg` is an original mark.
- `js/audio.js` builds a short noise buffer in the browser when the player turns room tone on. There is no audio file and no stream. The default is off. The case does not use the sound.

No font files, photographs, or third-party packs are included. Type is a local serif and sans stack.

No dialogue or character is taken from another game.
